# Sirio app icon provenance

Every asset in this directory derives from Sirio's own source artwork
(`assets/sirio-logo.png`). They are Sirio-generated assets, not vendored
third-party icons.

`icon_16.png` and the 16x16 frame of each `.ico` intentionally drop the orbit
ring and the orbiting body: at that size the ring resolves to a grey halo and
the body vanishes entirely, so only the four-point star is drawn. Every size
from 32 up carries the full mark.

`app-icon-attention.ico` is `app-icon.ico` plus the amber attention badge
(`#E08B52`, diameter 43.4% of the frame, centred at 76%/76%) — the same badge
geometry the icon has always used.
