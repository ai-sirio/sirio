A darker shell: Neutral gets its own evening coat, and the usage bar
stops interrupting.

**Neutral goes dark**

The default theme now paints its own surfaces instead of bezel's stock
grey: sidebars in `#191919`, terminal panes in `#141414`, the chat
transcript in `#232323` with the composer in `#313131`, and a solid
`#363636` hover everywhere. If you had grown used to the old
almost-black, this one is a touch softer and keeps every text contrast
at WCAG AA or better, light mode included.

**Usage bar refreshes silently**

The sidebar usage meter used to steal focus or flicker while it
updated. It now refreshes in the background and never pulls the rug
out from under what you are doing.

**Snappier worktree clicks**

Answering a worktree click no longer spawns a git process on the UI
thread, so switching worktrees stays smooth even while a fetch is in
flight.
