Sirio now recognises the agents you type by hand in a terminal tab and shows
their status, and it marks a chat or terminal that stopped while you were
away as unread. The main window is divided and measured like Zed's, and the
Files tree joins a chain of single folders into one row.

**Agents typed by hand in a terminal**

Type `claude`, `codex`, `opencode`, `pi` or `omp` in a plain terminal tab and
the tab gets that agent's mark, Claude's orange Clawd included, and shows
*working*, *waiting for you* or *finished*, as a tab Sirio launched does.

- A turn that finishes in a tab you are not looking at marks it unread and
  posts a notification. That also holds for a tab not shown since a relaunch
  and for a worktree not selected since.
- Terminals already open when Sirio updates keep the old detection until
  their host ends: after **End all sessions**, or after every terminal is
  closed and Sirio stays closed for over a minute. Closing the tabs of a
  running Sirio is not enough.
- In a tab whose session has already named its program, an agent title that
  arrives before the program is named gives the tab its mark only, and the
  first 2 seconds set no status from titles or screen text.
- OpenCode's status needs OpenCode v2's background service. With 1.x, or with
  no service running, the mark shows without a status.
- A turn shown both in its own tab and in a Show-session tab notifies once,
  and watching it in the Show-session tab counts as seeing it.
- Restarting a tab in the middle of a turn posts nothing and leaves no status.
- Claude, Codex and omp tabs that Sirio launched now show *finished* at the
  end of a turn, instead of *waiting for you*.
- On Windows a hand-typed agent is still recognised by its process. A
  hand-typed Claude shows no status there, because Windows' console does not
  pass Sirio's answer to its status question on to it.

**Sessions that stopped while you were away**

A chat or a terminal agent that stops while you are not looking at it is
marked unread until you look at it, and the mark survives a restart.

- The worktree row gets a dot at its edge and a bold title, and the session's
  pill gets a ring and a dot. The Sessions view, the rail icon and the tray
  menu carry the same mark.
- Every stop posts one desktop notification, chats included. A click on it
  opens that session and counts as seeing it, on macOS and Linux. Windows has
  no click route.
- On Linux, notifications now go straight to the desktop's notification
  service instead of through `notify-send`.
- A chat in a worktree that is not selected now keeps its status current, and
  a chat waiting on a question reads *waiting for you*.
- A terminal whose agent exited while Sirio was closed is marked unread at the
  next launch.

**The window, measured like Zed**

The panels keep their own cards, but the window is divided like Zed's.

- The sidebar is 300 px wide and the right panel 240 px. Widths you had
  already changed stay as they are.
- The title bar is 34 px, each tab strip 32 px and the status bar 30 px. The
  right panel's header is 32 px with 24 px icons.
- Sidebar and right panel text uses the interface size, 13 by default. Rows
  are padded 6 px and the file tree indents 20 px.
- The divider between the two centre halves remembers where you drag it.
- In a narrow window, once one side panel reaches its minimum width the other
  gives up the rest, so each centre half keeps its 320 px.

**Single folders on one row in Files**

A chain of folders that each hold a single folder is now one row, the way Zed
draws it: `java / it / acme / app / v2` instead of five rows and five clicks.

- The row acts as its last folder for selection, keys and the context menu,
  and carries the change mark of everything below it.
- In a narrow panel the start of the row is shortened, never the last folder.
- With hidden files off, dot files do not break a chain, so showing them can
  split a row. A symbolic link ends a chain.

**Fixes**

- A terminal running Claude Code no longer shows the Codex icon when its
  session title mentions Codex, OpenCode or Pi. A title now names an agent
  only by its first word.
- A file created inside an open subfolder now appears in the Files tree
  without closing and reopening the folder.
- A terminal flooded with coloured output keeps taking your keys, resizes and
  new views while the output runs, instead of freezing until it stops.
- Dragging a side panel's edge no longer turns *Automatic updates* back on,
  nor forgets the forge hosts you added in Settings.
- The right half of the centre no longer runs 1–2 px under the centre card's
  border.
