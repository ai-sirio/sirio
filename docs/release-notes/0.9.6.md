The first Stable release of Sirio.

Run Claude Code, Codex, OpenCode, Pi and Oh-My-Pi side by side in one native
window — one sidebar per project, one terminal per git worktree, and a glance
that tells you which agent is working and which is waiting on you.

**Install**

```
curl -fsSL https://dl.sirioai.app/install.sh | sh
```

On Windows, `powershell -ExecutionPolicy ByPass -c "irm
https://dl.sirioai.app/install.ps1 | iex"`. The script puts the
app where your OS expects it — `Sirio.app` in `/Applications`, the AppImage in
`~/.local/bin`, a per-user install under `%LOCALAPPDATA%\Programs\Sirio` — and
needs elevated access nowhere.

**What you get**

- Five agent CLIs as first-class panes, each launched the way its own binary
  expects, with worktree-local hook configuration written for you and your
  user-global config left alone unless you ask for it in Settings.
- A status per pane resolved from four independent signals — the agent's own
  lifecycle hooks, its terminal title, what it printed, and what is actually
  running in the shell — so a pane that needs you says so even when the agent
  has no way to announce it.
- A real terminal per worktree, built on libghostty-vt, that stays alive as you
  move around the sidebar.
- `sirioctl`, a small CLI that drives the running app over a local socket:
  list and open worktrees, create panes, read scrollback, send notifications.

**Updates**

This release turns the update channel on. Sirio checks once a day, verifies
every download against a signing key compiled into the binary, and applies
nothing it cannot verify. There is a Nightly channel too, built from `main`;
switching between channels means installing the other channel's build, not
flipping a setting.

macOS builds are signed with a Developer ID and notarized by Apple.
