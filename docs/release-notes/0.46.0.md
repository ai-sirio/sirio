A native Claude chat now shows what a subagent says and thinks, and on
Linux it shows MCP Apps widgets inline. Sirio also runs on a new version of
its UI engine.

**Subagents in the chat**

When Claude starts a subagent, the call is now a folded **Task** card instead
of a plain tool row. Unfold it to read the subagent's prompt, its text, its
tool calls and their results, in the order they arrived. Its thinking is
there too, folded. File paths in a subagent's text open in Sirio's editor.
In the Trace, a subagent's lane is labelled with the last thing it said.

**MCP Apps widgets (Linux)**

An MCP server can ship a small HTML view for a tool, called an MCP App. In a
native Claude chat on Linux, Sirio now shows that view inline in the
transcript, under the tool call. This works under X11, and on a Wayland
desktop where Sirio runs through XWayland, its default there.

- The widget runs in an isolated web view. It reaches only the domains its
  server declares, and it cannot open windows, download files or ask for
  permissions.
- When a widget wants to call one of its server's tools, Sirio asks you
  first with a card in the transcript. The card answers only to a click,
  starts on **Reject**, and arms **Allow** only once you have seen the
  arguments.
- A widget's buttons take clicks. Typing into a widget does not work yet.

On macOS, on Windows and on native Wayland, the call still shows as the
plain tool row.

**A new engine**

Sirio now draws its windows with gpui-pre 0.3.12 instead of bezel-gpui
0.3.8. Nothing should look different. If something does, please open an
issue.
