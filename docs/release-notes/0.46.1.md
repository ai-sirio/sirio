Sirio's chat and editor now run on the current release of Ely, the UI library
they are built on, and on macOS every window is paced the same way again.

**Ely brought up to date**

The chat, the editor and the dialogs now use Ely's own crates as published
upstream, with Sirio's changes kept on top. Most of it should look the same.
A few things changed on purpose:

- Pressing Enter in a dialog confirms on the press, not on the release. A
  dialog also puts the keyboard on its first control when it opens; in a
  dialog that deletes something, that control is Cancel.
- Hover effects (scroll bars, tooltips, hover cards) react to the pointer
  alone, without a click first.
- Tooltips use the theme's font, so a long one can wrap at another word.
- The items on the right of the editor's status bar sit a few pixels further
  left, and the popovers above them open 1 px higher.
- In a file with no line wider than the editor, a sideways scroll on the
  wheel or trackpad now scrolls the file up and down. A sideways step is also a little
  longer than before.

If something looks or behaves differently in a way that is not listed here,
please open an issue.

**macOS: one frame clock for every window**

On macOS 14 and later, Sirio now paces every window with the same display
timer it used before 0.46.0. This aims at a slow first draw of a tab opened
while Sirio is in the background.
