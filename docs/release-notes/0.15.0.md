The Activity panel now shows everything you have running rather than
only the worktree you are looking at, an agent that dies mid-turn says
why, and a chat no longer claims its context is empty when nothing ever
measured it.

**Every running worktree in one list**

The Activity section listed only the surfaces of the worktree currently
selected, so everything running elsewhere vanished from the panel the
moment you looked at something else. It now lists every mounted
worktree's surfaces, each row carrying its own project and branch, with
the worktrees that want attention first. Selecting a row belonging to
another worktree switches there and opens it. Closing one switches there
first and then always asks before closing — the thing being closed is
something you were not looking at a second earlier, and the dialog is
the only place that can still say what it is.

**An agent that dies says why**

When a chat agent went away in the middle of a turn, the only thing
shown was that the connection had closed: the same message whether the
agent had crashed, exited cleanly, or been terminated by Sirio itself.
The error now names the cause — the exit code the process reported or
the signal that killed it, the agent's own last words from its error
output, and, when Sirio's inactivity watchdog was what ended it, that it
was the watchdog and after how long.

**Waiting on a permission no longer stalls the session, or kills the agent**

A permission request left open froze the rest of that chat: no further
output arrived while the card waited for an answer, and a second request
from the agent could not be answered at all. Worse, that wait counted as
silence from the agent, so an agent that had done nothing but ask a
question was killed ten minutes later. Time spent waiting for you is no
longer counted against the agent, the session keeps streaming while a
card is open, and a card that expires is answered as a refusal rather
than as a protocol failure.

**Context reads as unknown instead of zero**

Agents that never report how much of their context window is in use —
Pi among them, whose adapter does not send that figure at all — showed
`Context 0%`, stating as measurement something nobody had measured. The
chip now shows a dash, and the details say the agent has not reported a
context window size instead of printing `0 / 0 tokens`. Agents that do
report their usage are unchanged.

**Quieter thinking and loading indicators**

The orbs drawn while an agent is thinking, and while a view is still
loading, are painted in a neutral gray.
