Claude Code's `/ide` now connects to Sirio: Claude sees your selection and
your diagnostics, and proposes each edit as a diff you accept or reject in
Sirio. A native Claude chat also lists the hooks Claude Code loaded, says
which usage limit is near, and shows `/usage`.

**Sirio is the IDE for Claude Code**

Every Claude Code running in one of Sirio's terminals can connect to Sirio
with `/ide`:

- Claude sees the selection in Sirio's editor, and **Send selection to
  agent** gives it the file and lines as `@file#L10-20`.
- Claude reads the diagnostics of Sirio's language servers.
- Each edit Claude proposes opens as a diff in a **Proposal** tab, with
  **Accept**, **Reject**, **Edit** and **Reject with comments**. Nothing
  answers a proposal without you: closing the tab, quitting Sirio, a lost
  connection or removing the worktree never accepts it.

The bridge is on by default. To turn it off, use **Connect Claude Code to
Sirio (/ide)** in Settings, under AI Providers, Claude. If Sirio was
closed for more than a few seconds, restart Claude Code in that terminal: it
stops retrying the connection after about 20 seconds, and `/ide` does not
bring it back.

**Hooks in the session panel**

The session panel of a native Claude chat has a read-only **Hooks** card. It
lists the hooks Claude Code loaded for the session, grouped by event, each
with where it comes from (User, Project, Local, a plugin, the session or
your organization), its matcher and, unfolded, its command. A hook that
does not run is marked disabled, and a note says why when your
organization's policy or a mode limits hooks.

**Usage limits and `/usage`**

The usage-limit line in a native Claude chat now says which limit it is, how
full it is and when it resets, for example *Approaching the 5-hour usage
limit: 92% used, resets at 15:15.* or *Weekly usage limit reached, resets at
Thu 15:15.* When extra usage runs out, it names the budget: your individual
spend limit, your team's pooled budget or your channel's monthly spend
limit. It used to read *Usage limit reached* even for a warning.

`/usage` and the other commands Claude Code answers on its own now show
their answer in the chat. On a claude.ai subscription, `/usage` shows a
**Usage** card with the plan's limits.
