A file an agent names in a chat response now opens in the editor with a
click, the Trace follows background agents to their end, and the file
editor scrolls sideways and shows a text cursor again.

**File paths in a chat response are links**

When an agent writes a path to a file in its answer, the path is now a link,
and a click opens the file in Sirio's editor.

- It works in the agent's prose, in `inline code` and in Markdown links,
  for relative and absolute paths and `~/…`. A path that starts with `/`
  but exists only inside the worktree is found there too.
- A line number comes along: `path:42`, `path:42:7`, `path:42-50` and
  `path#L42` open the file at that line. A Markdown file opened at a line
  shows its source, since the preview has no lines.
- An open tab is reused. Dragging across a path selects text and opens
  nothing.
- Only paths to files that exist become links, so versions, dates and
  missing files stay plain text. Your own messages, tool cards and code
  blocks are left as they were.

Links in an agent's answer are now limited to what is safe to follow. A web
link (`http`, `https`, `mailto`) still opens in the browser and a file that
exists opens in the editor. Everything else is no longer clickable in a
chat response: app schemes such as `vscode:` or `smb:`, `file://` links to
folders, relative links to files that do not exist, and `#anchors`. A local
picture is shown only when it is an existing file of up to 10 MB; otherwise
you see its description. An agent's text can be steered by what it reads, so
it no longer gets to hand a link straight to the system.

**Background agents in the Trace**

When Claude Code sends agents to work in the background, the Trace now
follows them until they finish, instead of stopping when the main thread
answers.

- The turn stays *Live* while its agents run, and their lanes keep filling.
- Its cost reads *≥ $x* until the last agent is done, then the exact
  amount. The short turns Claude Code starts by itself after each agent are
  counted in that cost and not drawn as turns of their own.
- The wait for a model's first token is now drawn as part of its call, so
  the timeline no longer shows gaps between a tool and the next model call.

**Fixes**

- The file editor scrolls sideways again, so the end of a long line can be
  read: with a sideways wheel or touchpad swipe, Shift and the wheel, the bar
  under the code, or End and Home. The line numbers stay in place.
- The pointer over code in the file editor is a text cursor again, not an
  arrow.
- In the file editor's and the terminal's right-click menus each entry is
  one line. Why an entry is unavailable now shows as a tooltip when you rest
  the pointer on it.
