Oh-My-Pi now works in chat views as well as in a terminal, and long
text in the chat no longer pushes a row's controls past the edge of
its card.

**Oh-My-Pi over the agent protocol**

Oh-My-Pi was reachable only through a terminal pane: the app knew of
no way to talk to it over the agent protocol, so a chat view with it
was never offered. Its binary does serve that protocol through its own
subcommand, and the app now uses it — a capability confirmed against a
real Oh-My-Pi, not assumed from a description of one.

**Long text stays inside its card**

Several chat rows handed their width to text that comes from outside
the app: a file path, an edit summary, the label that closes a turn,
the title of a saved session. One long enough grew the row instead of
the row's controls, and everything on the right — line counts, revert
and confirm buttons, timestamps, the delete control — was drawn past
the card's border, unreadable and unclickable. That text is cut to a
single line with an ellipsis now; the controls keep their place.

**Permission buttons wrap**

A permission request can offer several answers with long labels, and
they were laid out on one row that ran off the card. The buttons now
wrap onto as many lines as they need, so every option stays visible
and clickable.
