A quality release: the terminal gets the font the agent TUIs expect, the
Files panel stops polling, and a few things that behaved unevenly across
platforms now behave the same everywhere.

**The terminal ships its own font**

Sirio now bundles JetBrains Mono Nerd Font Mono and uses it for every
terminal pane. Before, the terminal used whichever monospace face the machine
happened to have, and on a stock Windows install that meant Courier New: a
slab serif with none of the Powerline and icon glyphs that Claude Code, Codex
and the other agents draw their status lines with, so the coloured "pills"
ended in little boxes. Those glyphs now render as designed, bold and italic
included, on Windows and Linux alike. macOS keeps SF Mono, as before. If you
have your own Nerd Font installed, it is no longer needed for Sirio, but it
does no harm.

**Files panel: refreshed on change, instant on switch**

The Files panel used to re-walk the tree on a timer. It now refreshes when
something on disk actually changes or when you switch views, and the settled
tree stays on screen while the refresh runs in the background. Switching
between worktrees is instant, because the trees of your mounted worktrees are
prepared ahead of time. Build output directories are ignored by the watcher,
so a `cargo build` in a pane no longer makes the panel flicker.

**Removing a worktree asks first, then gets it done**

Removing a worktree — from the row's × or its context menu — now shows a
confirmation naming the branch and warning that uncommitted changes in that
checkout are lost. Once confirmed, the removal is forced through: a checkout
carrying a large build tree used to hit a 10-second limit and leave the row
behind with a raw git error under it. It now gets its own generous deadline,
and if git still refuses, Sirio deletes the checkout itself — with guards so
it only ever removes a linked worktree, never a home directory or the
repository.

**Smaller things you may notice**

- Settings → Appearance → *Interface font size* now scales the worktree names
  in the sidebar too; they were the one string that stayed at a fixed size,
  and long names were clipped instead of growing the row.
- The Local changes panel draws its chrome — file rows, section headers,
  Discard/Unstage/Open diff — in the same face as the sidebar. Diff code and
  line numbers stay monospace.
- A terminal pane you are not looking at no longer makes the whole window
  repaint on every line of output. On a busy hidden pane this cut the window's
  redraw rate by over 90% and the process's CPU use by roughly 40%.

**Updating**

The update prompt in Sirio takes you there. If you are on 0.9.6, which cannot
start on many CPUs, reinstall by hand as the 0.9.8 notes describe; from 0.9.8
the normal prompt is all you need.
