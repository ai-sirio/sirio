This release is all repair, most of it in the chat pane: a reasoning
section that opened onto nothing, popovers pressed against their own
border, cards that scrolled the transcript behind them, and red error
banners for MCP servers that were never the conversation's business. The
file editor also loses a row it did not need.

**A thought you can open has something in it**

A Claude Code chat drew a `Thought for 3s` that expanded onto an empty
box. Nothing was lost on the way: `claude` sends the reasoning block for
every model, but only some models carry its words. For the rest the wire
carries the block, a signature proving the reasoning happened, and
nothing to read — so Sirio stops building a section out of it. A
reasoning section on screen now always has something in it.

A restored transcript could also break one thought into a separate
section per fragment. It no longer can.

**The editor stops repeating the tab**

The file editor drew two stacked bars above every document. The upper one
said what the tab already says — the file's path, an `● edited` mark
beside the tab's own dirty dot, a language chip — and spent a full row
doing it. It is gone.

Preview and Code move to the right end of the row that remains, as two
icons, and that row is now drawn for every Markdown file rather than only
in Code mode: with no header left, those icons are the only way out of
Preview. The formatting controls stay Code-only, since Preview is a
reading surface with nothing to format. The language name is the one
thing that loses its last place on screen.

**Scrolling a card no longer scrolls the transcript behind it**

The wheel over an inner well — an Execute tool's output, a thought's body
— moved the well and the whole chat at once. Each well now holds the
wheel while it still has room to travel and hands it back at its edges,
so the transcript takes over exactly where the card runs out.

**The chat popovers sit off their own edge**

The context ring's usage popover, the composer overflow menu and the Chat
History menu mounted their rows straight onto the card, so the first row's
text and the rows' hover wash sat flush against the border — an inset of
zero, measured. They now carry the same 4px every other menu in the app
has always had.

**An MCP server Sirio did not start is not a chat error**

A Claude chat runs with your own settings, so a broken MCP server — one
named in `.mcp.json`, or a plugin that cannot connect — arrived as a red
error banner in the transcript, in every chat, every time. Those failures
no longer speak as errors in the conversation; they are still there in
the death report if the agent itself goes down.

**The usage bar survives a worktree switch**

Selecting another worktree rebuilt the status bar from scratch, so the
numbers you were reading vanished on the click and returned only once a
fresh fetch had come back, and the "Update available" indicator blinked
with them. Only the `branch · path` label belongs to the selected
worktree; the fetched numbers and the update state belong to the session,
and now stay put.
