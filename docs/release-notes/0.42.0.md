A native Claude chat now shows the tasks Claude runs in the background and
lets you stop them, and its status follows what Claude itself reports
instead of guessing from the turn.

**Background tasks in a native Claude chat**

A background shell, a Monitor or a background agent that Claude starts used
to show only as a count on the composer's chip. Now you can watch and stop
each one.

- Click the chip to open a list of the running tasks, each with its
  description, its kind and a **Stop** button.
- On the Trace card, a running background agent has **Stop** on its own
  lane, and the other tasks sit in a Background group with the last line
  of their output.
- The Trace tab shows a strip under the tree with each task's state, a
  **Stop**, and a shell's last 6 lines of output.
- Output is read only while it is on screen: a hidden chat, a folded card
  or a closed tab asks Claude for nothing.
- **Stop** reads *Stopping…* until Claude reports the task ended.
- Escape closes the list before it would cancel the turn. The narrower
  composer rows keep the count in ⋯ without the list.
- A Claude Code that does not share a task's output, as 2.1.257 does not,
  still lists its tasks and still stops them; their output is just not
  shown.

**A chat's status follows Claude**

A native Claude chat used to read *Done* as soon as the main turn ended,
even while a background agent Claude had started was still working. It now
follows the state Claude reports for its own session: the sidebar, the
Sessions view and the Trace card read *working* until Claude is idle, and
*waiting for you* while Claude needs an answer. A turn Claude starts on its
own, such as a Monitor waking up, does not mark the chat as working.

**Fixes**

- Saving which session each tab resumes no longer happens on the window's
  thread, so a slow disk cannot stall the interface.
