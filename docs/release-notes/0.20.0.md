Four things you can see, and one you could not.

**Folders open and close**

Every directory in the Files tree carries its own mark now — a closed
folder when collapsed, an open one when expanded — and the disclosure
arrow that used to say the same thing is gone. So is the 10px slot it
lived in, which was always empty beside a file and which pushed directory
names out of line with file names. Files and folders read as one column.

**The agent marks are the agents' own**

Codex had been wearing OpenAI's generic knot; it has its own mark now.
Claude, OpenCode and Pi keep the shapes you know, and Oh-My-Pi its
gradient. What changed underneath is that they all come from one icon set
drawn on one grid, instead of two sets that had to be nudged into
agreeing about size — so the marks carry the same weight beside each
other without anything being adjusted by hand.

**A finished tab's dot is the size of a running one**

A green (done) or amber (waiting) tab drew a mark filling the whole 14px
slot while the running tab beside it read as a 6px dot: one glyph at two
sizes, depending on which state it stopped in. They are one size now.
What separates running from done is what always should have — motion, and
where the brightness sits inside the mark.

**The colour icons are sharp**

Every polychrome glyph in the Files tree, and Oh-My-Pi's mark with them,
was being rasterised at a fraction of the size it is drawn at and then
stretched to fit. They are rendered at the size they are painted now.

---

That last one had been true since those icons were first drawn, and no
one reported it. A raster that comes out too small is stretched rather
than refused, so the fault had no symptom beyond a softness you would
have to be looking for — and it surfaced only because a new mark needed
the same code path, and arrived with a test that measured what came out
of it rather than reading what went in.
