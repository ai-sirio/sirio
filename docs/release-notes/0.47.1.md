Sirio 0.47.1 fixes two ways a chat reply could close the app, and the chat
now draws pictures by the same rule as the Markdown Preview.

**A reply can no longer close Sirio**

- A chat reply, or a Markdown file in the Preview, closed Sirio when it held
  a reference link whose label broke across two lines of a quote, or a link
  definition right after a list with text on the next line. Both now draw as
  intended.
- A reference link whose label matched two definitions only loosely (`ı` and
  `i`, for example) could open the wrong address. It now opens the one the
  Markdown rules pick.
- If the Markdown reader still fails on some text, that text is shown plain
  instead of closing the app. A chat reply that hits this stays plain until
  its turn ends.

**Pictures in the chat follow the Preview's rule**

- A picture whose path holds `?`, `#` or `%` now draws the exact file the
  path names.
- A picture whose path names a Windows device name (`NUL`, `COM1`, `aux.png`
  and the like), on any system, shows its alt text, as in the Preview. Sirio
  no longer looks such a name up on disk, which on Windows could hang the
  window.

**Sidebar**

- With a larger interface font, the pinned project header now changes to the
  next project at the right place while you scroll.
