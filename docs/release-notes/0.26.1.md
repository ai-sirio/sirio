Two repairs to the layout 0.26.0 introduced. A right pane you hid can be
brought back from the command palette, and the sidebar's Projects and
Sessions switch is drawn as tabs.

**The right pane comes back from the command palette**

The × at the end of the right pane's tab strip hides the pane without closing
its tabs, and each worktree remembers that, across restarts too. Until now,
once the pane was hidden nothing on screen brought it back. The × and the
empty pane's Hide Pane button disappear with the pane, so only Ctrl+Shift+B
could restore it. The command palette now lists Toggle Right Pane, with that
shortcut, next to Toggle Right Panel. It was the only window shortcut the
palette did not list.

**Projects and Sessions are tabs**

The switch at the top of the sidebar is now a pair of tabs, each with an
icon: a folder for Projects, a speech bubble for Sessions. The current view is
underlined, as in the centre panes' tab strips. The tabs start at the same
left edge as the project rows below them. In a narrow sidebar the labels are
shortened, so the + beside them is never pushed off the edge.
