The sidebar gains a Sessions view, and closing a chat no longer throws it
away. A terminal or a chat can now sit in either centre pane and move
between the two. An agent's question is answered from a panel above the
composer, and the Markdown preview draws HTML, Mermaid and PlantUML.

**Every session in one list**

A switch at the top of the sidebar flips between Projects, the worktree
tree, and Sessions: every agent session in one list, most recently active
first. Each row shows the session's title and agent, its project and
worktree, how long ago the agent last did something, and the same status
mark the worktree rows use. Sessions on worktrees you have switched away
from are listed too. Clicking a row takes you to its worktree and tab, and
the × that appears on hover closes it. While Projects is showing, the
Sessions switch carries a badge when a session needs your input or has hit
an error. The sidebar remembers which view you left it on.

The Activity view in the right-hand panel is gone. The Sessions list
replaces it.

**Closed chats are kept**

Closing a chat tab now archives the chat instead of deleting it. The
Sessions view lists archived chats under Closed, most recently closed
first. Clicking one reopens it in its worktree and resumes the agent's
session. The trash action, confirmed with a second click, deletes it for
good. The archive holds at most 50 chats, none older than 30 days.

**Terminals and chats move between the centre panes**

A terminal or a chat can now sit in the right-hand pane as well as the
left: beside a file, a browser or Changes, or beside another agent. There
are four ways to move one across:

- Drag its tab onto the other pane's tab strip. A bar marks where it will
  land.
- Drag it onto the other pane's body, which puts it at the end of that
  pane's strip.
- Right-click the tab and choose Move to Right Pane or Move to Left Pane.
- Press Ctrl+Shift+M. It moves the tab you are working in and takes the
  focus with it, so pressing it again brings the tab back. The command
  palette offers the same command as Move Tab to Other Pane.

A moved tab keeps running. An agent working in a terminal carries on
through the move, and a chat keeps its conversation. The pane it left shows
the neighbouring tab. Only terminals and chats move: the browser, the
editor, Changes and Project Settings stay on the right.

New terminals and chats still open on the left. An empty right-hand pane
now also offers Terminal and Chat, and those open straight into it. A
restart puts every moved tab back in the pane you left it in, and shows the
right pane again if the tab you were on is there.

**Answering an agent's question**

When an agent asks something, the question now opens in a panel directly
above the composer. It might ask for permission to run a command, for one
of a few answers, or for approval of a plan. Before, it appeared as a card
up the conversation, announced by a yellow bar. The panel shows the whole
question, and a long command scrolls inside it rather than pushing the
composer away. Each answer is on its own numbered row:

- ↑ and ↓ move between answers.
- Enter picks the selected answer, and 1 to 9 pick one by number.
- Escape withdraws the question.

Where the agent accepts an answer of your own, you can type one instead.

For half a second after a question appears, its answers ignore keys and
clicks, so a keystroke meant for the composer cannot answer a question you
have not read yet. The conversation keeps a record of each question and the
answer given. Claude Code's questions show their own titles, where before
every one was headed *Question*.

**The Markdown preview draws HTML and diagrams**

A Markdown file's Preview now reads the HTML a README typically carries:
headings, line breaks, rules, bold and italic, links, `<kbd>` and images
with a width. Remote images load. Scripts, styles, frames and forms are
dropped along with their content. Nothing is executed, and there is no web
view.

Mermaid diagrams are drawn directly, in the colours of the current
appearance.

PlantUML diagrams are drawn by the `plantuml` on your PATH, inside its
sandbox, which means no network and no local includes. Versions older than
1.2023.9 are refused, because their sandbox can be escaped. Without a
usable `plantuml`, a note under the diagram says why it was not drawn.
Settings → Markdown preview can name a PlantUML server to use instead. That
setting is off by default, because it sends the diagram's source off the
machine.

Diagrams are drawn in the background and cached, so they never hold up
scrolling or typing.

**Long lines scroll sideways**

A file whose lines are wider than its view now shows a horizontal scrollbar
under the code, instead of cutting the lines off. Changes does the same for
its diff. In the unified view the code scrolls under one bar while the line
numbers stay put. In the side-by-side view each side has its own bar and
scrolls on its own, with the rows still lined up. The bars appear only when
something is wider than its space.

**Smaller changes**

- **New Chat in a worktree's menu asks which agent to use.** Right-click a
  worktree and choose New Chat. It lists the agents that can start a chat,
  as the tab strip's + menu does, and Other agents… opens Settings → Agents.
  The menu is also wider, so Remove Worktree and Remote Branch fits on one
  line.
- **A worktree you switch away from keeps its running mark** for as long as
  its agent is still working.
- **Projects that are not git repositories no longer show git errors.**
  Changes shows its ordinary empty state instead of an error with Retry. A
  broken repository still reports its error. When a project gains or loses
  its `.git`, Changes catches up once the project list refreshes.
- **The empty panes' buttons no longer show keyboard shortcuts.** The
  shortcuts still work, and the command palette still lists them.
- **The × at the end of the right pane's tab strip** now sits on the same
  colour as the strip, not on a darker patch.
