Sirio now draws all of its Markdown with Ely, lets you choose the app's font,
and has a tidier sidebar.

**Markdown drawn by Ely everywhere**

The chat, the Markdown Preview, the file view and change requests now draw
Markdown with Ely's document renderer, the same one on every surface. Long
chat replies also draw faster while they stream.

The Preview gains:

- LaTeX math (`$…$`, `$$…$$`, `\(…\)`);
- GitHub alerts (`> [!NOTE]`, `> [!WARNING]` and the others);
- footnotes and emoji shortcodes;
- a `[[toc]]` table of contents, heading anchors, an outline panel and a
  reading-progress bar;
- strikethrough and bare web addresses, which change requests read too.

A few things look or behave differently:

- Markdown uses the font chosen in Settings (see below).
- Pictures, and diagrams in the Preview, are drawn without a frame or a
  caption. A picture inside a sentence gets a line of its own.
- In a chat reply, `<url>` chips, bookmark cards and `![alt|480]` widths are
  gone.
- A copied list has no blank lines between its items.
- In the chat, a drag that ends on a link selects text instead of opening the
  link.
- The Preview's right-click menu lists the Markdown items above the file
  items.
- Text nested more than 32 levels deep, in quotes or lists, is shown as one
  plain paragraph.
- In the Preview, a picture whose path names a network share or a Windows
  device name (`NUL`, `COM1` and the like) shows its alt text instead.
- A `file:` or `#…` link in a change request no longer opens in another app.

**Choose the app's font**

Settings → Appearance → Interface has a new **Font** row, above Font size. It
picks a pair: one face for the interface and one for code. The change applies
at once, and every pair ships inside Sirio:

- Atkinson Hyperlegible, the new default;
- Inter + JetBrains Mono;
- IBM Plex;
- Red Hat;
- Recursive;
- Figtree + Fira Code;
- Geist, the font Sirio used until now.

**A tidier sidebar**

- Project rows no longer sit on a band, and each folder icon lines up with
  New Chat's icon.
- A worktree is one line: its name and the icons of its tabs. The task title
  and the worktree's comment are in the card that opens on hover.
- A project folder that is not a git repository shows its folder name, muted,
  where a branch name would be.
- A thin line runs down the left of each open project, beside its worktrees.

Fixed: a moved project folder that is not a git repository was listed as
"main (missing)".
