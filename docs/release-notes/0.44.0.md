The sidebar has a new shell: a title menu, a bell for chats that need you,
search, and a card that shows a worktree's tabs on hover. A native Claude
chat can now switch its connectors on and off, reload its plugins and
skills, and say what Claude Code reports about retries, notices, refusals
and a failed start.

**A new sidebar**

The sidebar keeps its worktree cards and gains a shell around them:

- The header has a title menu to choose **Projects** or **Sessions**, a
  **bell** that lists the chats with an error, a question or unread output,
  and **Search**, which opens a filter field. Esc closes the field.
- A **New Chat** row starts an agent in the current worktree.
- Each project is a row with its folder icon; **+** and **⋯** appear on
  hover. The section header folds the whole list.
- On a worktree card, **★** sets or unsets the primary worktree and **×**
  removes it, both shown on hover. Git's main checkout is never offered for
  removal, whatever its star says.
- Holding the pointer on a card shows a card beside the sidebar with the
  branch, the last event, the project and one line per tab.
- The list's scrollbar fades when you are not scrolling.

A pill selected with the arrow keys is now forgotten when the list takes
focus, so Backspace cannot close a tab nobody is pointing at.

**Connectors and plugins in the session panel**

In a native Claude chat's session panel, each connector has a switch. Claude
Code saves the choice for the folder, so a new session there starts with
the connector the same way. The **Plugins and skills** row reloads Claude
Code's plugins and skills without restarting the chat. When the reload would
change Claude's tools and reset the prompt cache, Sirio says which tools are
added and removed and offers **Reload anyway**. The row waits while a turn
runs.

**What Claude Code says, in the chat**

A native Claude chat now shows Claude Code's own messages about its work:

- While Claude Code retries a request, a status line above the composer says
  so, for example *Retrying 2 of 10 in 2 s: overloaded*. Claude Code's
  notifications appear on the same line.
- A refusal shows Claude Code's own sentence, and its informational lines
  appear in the transcript.
- When Claude Code cannot start, the chat says why, for example an invalid
  configuration file and its path, in place of a generic transport error.

Two fixes come with it. An answer that Claude Code sent again after a broken
stream used to be invisible; it now appears under the cut reply. A refused
`--resume` no longer leaves an "ended" footer in the fresh session that
replaces it.
