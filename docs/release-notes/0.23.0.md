This release is mostly the code editor and the chat pane. An LSP finding
moves off the gutter and onto the code it is about; an empty line stops
being a place you cannot click, type or select. The chat learns the names
of seven more tools, tells you what a slash command takes, and passes on
the things a session says about itself. A focused terminal gets its own
control chords back, and a worktree deleted from a shell finally leaves
the sidebar.

**A warning underlines the code, not the margin**

An LSP finding used to show as a coloured dot in a narrow column beside
the line number — which told you *a* line had something wrong on it, and
nothing about where. It now underlines the code itself, a wavy rule in
the severity's colour: red for an error, amber for a warning, faint for
the rest. The dot's column is gone and the line numbers move left into
the space it held.

Two things the dot could not do come with the change. A finding that
spans several lines now marks every line it touches, rather than only the
first — a four-line type error used to mark one. And a finding that
covers no text at all, the `expected ;` kind, takes the character next to
it instead of drawing nothing, which read exactly like a clean line.

**An empty line is a line again**

A blank line in the editor could not be clicked into, could not be typed
on, and never showed the caret. A line's click target was only as wide as
its letters, so a line with no letters had no click target at all, and
every mouse gesture on it was refused before it started.

The same measurement made the space to the right of every short line dead
too. Both are fixed: a click anywhere on a line's row now lands where you
aimed, and past the last character it lands at the end of the line. A
blank line inside a selection also shows that it is selected, instead of
being the one row a drag appeared to skip.

**The chat names seven more tools**

`EnterPlanMode`, `ToolSearch`, `LSP`, `Monitor`, `TaskStop`, `SendMessage`
and `Artifact` used to draw as their bare wire name under the neutral
icon, with no location and nothing to read. They now have rows of their
own. `LSP` earns more than a title: its file and line make a location the
transcript can follow, the way a `Read`'s offset already could.

**A slash command says what it takes**

The CLI has always sent an argument hint beside each command's name, and
the picker dropped it — you accepted `/code-review ` and the composer told
you nothing about what belonged after it. The hint now rides beside the
name, on the same single line the row has always been.

**A session's own notices reach you**

A turn reports more than its answer: that the context was compacted, that
a rate limit is close, that background tasks started and finished. All of
it arrived, was recognised, and was thrown away. Those now reach the
transcript.

**The right button copies from the transcript**

Select-all and copy on a right-click, where every other text surface in
the app already had them.

**A focused terminal keeps its own control chords**

`ctrl-t`, `ctrl-o`, `ctrl-s` and `ctrl-l` were caught by the window before
the terminal ever saw them, so the keystroke never reached the program
running inside. Those are that program's keys — `ctrl-o` opens Claude
Code's expanded output, `ctrl-l` clears the screen — and they now pass
through to it. The `ctrl-shift-` family stays Sirio's, which is the half
meant to work from inside a terminal.

**A worktree removed behind Sirio's back leaves the sidebar**

A checkout deleted from a shell, or torn down by an agent runner, came
back at the next refresh and was then written to the database, so it
survived restarts and nothing in the UI could clear it. A row is now kept
only while the checkout is still on disk or one of our terminals is still
live in it — so an agent whose checkout vanished under it keeps its row
and can still be closed, while a worktree you removed yourself goes away.
A row already stuck heals itself at the next ordinary refresh.
