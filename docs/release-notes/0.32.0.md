Your terminals now live outside the app: an agent keeps running through a
crash, a Force Quit, a Quit or an update, and Sirio picks it up again when it
starts. Updates arrive in a card you can act on, and two new base colours
join the theme.

**Terminals that outlive the app**

Every terminal Sirio opens now runs in `sirio-host`, the background process
0.31.0 introduced, instead of inside the app.

- **Quit no longer stops your agents.** Quitting detaches from the host; the
  next launch reattaches every terminal it left, with its scrollback. The
  same holds when the app crashes or is force-quit.
- **Nothing is lost on the way.** A terminal the host still runs but no tab
  shows is adopted into the worktree holding its directory. After a reboot,
  when the host is gone too, tabs come back as before: a new shell with the
  old scrollback, and the agent resumed where it supports it.
- **Closing still ends things.** Closing a tab, a worktree or a project ends
  the terminals inside it, as before.
- **If the host goes away,** the tab says *Session lost* and offers Restart;
  the next terminal starts a new host. When no host can be used at all,
  terminals run inside the app as they always did, and a banner says why.
- The host from 0.31.0, which ran no terminals, is replaced on the first
  launch.

**Updates in a card**

When a new version is available, at launch or when a check finds one while
you work, a card in the bottom-right corner offers it.

- **Restart to update** downloads, verifies and installs it, then relaunches
  into it.
- **Install without restarting** appears when agents are at work: the new
  version waits for the next launch, and the card warns that a restart would
  stop them.
- **Later** hides the card for that version until the next launch.
- While a download or install runs, the card can be closed; the status bar's
  indicator says *Updating…* and brings it back. A failed update offers
  Retry when one can help.

A card that appears while you work never takes the keyboard.

**Appearance**

- Two new base colours, **Argilla** and **Grafite**, under Settings →
  Appearance → Base color.
- The chat composer now wears the theme's colours: the same surface as the
  other cards, no white frame while you type, and a quieter send button.
- In the sidebar, *Projects* and *Sessions* are a segmented switch, with
  Expand all, Collapse all and *+* on a row of their own beneath it.

**Fixes**

- In light mode, some controls drew with the dark palette until the theme was
  changed once.
