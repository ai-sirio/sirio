This release makes the effort a Claude chat runs at both complete and
directly settable, and stops a worktree that runs chats and nothing else
from going missing in Activity.

**Every effort level the model actually offers**

A Claude chat offered Low, Medium and High. The CLI has taken five all
along — the two above High, `xhigh` and `max`, were simply unreachable from
a chat tab while the terminal pane beside it took them without comment.
They are there now, and so is Ultracode, which pairs the highest effort
with Claude's own multi-agent orchestration.

The list is no longer written down inside Sirio at all: it comes from the
session, per model. A model that offers five shows five, one that offers
three shows three, and Haiku — which has no effort setting — no longer
shows the control at all. It used to be offered three levels it never had.

**Effort is a slider, beside the model**

The levels used to be a row of chips inside the model picker, which meant
opening one control to find another. Effort now has its own label next to
the model: click it and the levels are a track you drag, with the level you
are on named above it. "Use the model's default" sits below the track
rather than on it, because a default is not a point on a scale — on most
models it resolves to High, well above the bottom.

To make room, the context meter lost its percentage. The ring beside it
still fills as the window fills and still turns red past 80%, and the exact
figure is one click away in the popover, where it always was.

**A worktree with only chats appears in Activity**

Activity listed a mounted worktree only when it had a terminal open, so a
worktree running nothing but chats was invisible there — and a parked chat
tab could not report what it was doing. Both are fixed.
