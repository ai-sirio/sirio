The chat's effort is now a list and every chat starts on High, Java projects
that use Lombok stop showing errors that are not there, and Sirio's fields,
tooltips, menus, scrollbars and Settings pages are now drawn with Ely, like
the chat.

**Effort is a list, and every chat starts on High**

The chat's effort slider is now a list.

- Each level the agent offers has a row with a stepped bar. Ultracode notes
  "+ workflow", and when the agent offers it, a muted *Default* row at the
  bottom keeps the model's own level.
- Every chat asks its agent for High, when the agent offers it: when it
  connects, after a restart, on a new conversation and after a model
  switch. A level you pick wins, and it survives a model switch that
  offers it.
- An agent that refuses a level no longer ends the chat. The chip goes back
  to the last level the agent accepted.

**Lombok in Java projects**

When a project's `pom.xml`, `build.gradle` or version catalog mentions
Lombok, Sirio's built-in Java language server (jdtls) now starts with
Lombok's agent, so the getters, builders and constructors Lombok generates
are no longer errors.

- The jar is the newest Lombok in your Maven repository (including a
  `localRepository` set in `~/.m2/settings.xml`) or Gradle cache. Sirio
  ships no jar of its own: with none in the caches, nothing changes.
- Once the server is up, the project is built once in full, so files you
  never opened lose their stale errors too.
- If the server does not start with the agent, Sirio starts it again
  without it, and the project keeps its Java support.
- A newer Lombok jar in the caches, or Lombok added to a build file while
  Sirio runs, restarts the server once.
- A `java` entry you wrote yourself in `languages.toml` is left as it is.

**Fields, menus and Settings drawn with Ely**

- Framed fields are 28 px high, with Ely's radius and text. The composer's
  caret is thinner.
- Tooltips have a solid fill and a shadow and open below the pointer. The
  sidebar's are the same size as the others.
- Menus are a solid panel with a shadow and 28 px rows. A long label ends in
  an ellipsis inside the menu, and the tab menus' text follows the interface
  size.
- The scrollbars of the Markdown preview, the CI log, the Trace tab and a
  thought have a translucent thumb, a little further from the edge.
- Settings buttons are smaller, and an error on a Settings page is a filled
  alert whose text can be selected and copied. The status bar's usage meter
  is a thin bar that glides between values.

The keys in a text field change too:

- The editing keys work in every field. On macOS: Cmd+Backspace,
  Option+Delete, Ctrl+K, Ctrl+A/E/B/F/H/D, and Ctrl+N/P in a field of
  several lines. On Linux and Windows: Ctrl+Delete.
- Moving and deleting by word stop at the same places in every field: a
  word is a run that holds a letter or a digit.
- On macOS, Ctrl+K in a text field deletes to the end of the line.
  Ctrl+Shift+P still opens the command palette.
- Shift+Enter and Alt+Enter no longer submit a one-line form or the address
  bar. Enter and Ctrl/Cmd+Enter still do.
- Tab on a Settings page now stops on every button.
- Each deletion is its own undo step.

**Fixes**

- Ctrl/Cmd+C now copies text selected in a chat response.
- A reply no longer comes out garbled when a background agent finishes in
  the middle of it.
- A long background-task notice wraps inside the chat instead of running off
  both sides.
- A diagnostic message with line breaks, such as TypeScript's, no longer
  draws a missing glyph or a two-line row in the Problems drawer.
- A language server that fails its startup handshake is now stopped,
  instead of being left running.
- A project added or removed, or a label, icon or primary mark changed,
  just as Sirio's window got the focus back is no longer undone by the
  refresh that follows. Before, an added project could also disappear from
  the saved list.
