Browser automation reaches the command line, and the app it drives no
longer dies the moment a page opens on Linux.

**Drive the browser from the command line**

`sirioctl browser` exists now, with the eight verbs that work: open,
navigate, get, snapshot, act, wait, eval and console. Point it at a
page, read what is on it, click or type into elements by reference.
Every one of these was refused as an unknown command until now.
Navigation means an address only: back, forward and reload are not
there yet, and neither is capturing the page as an image, because the
engine behind this surface offers no way to grab its pixels.

**Opening a page no longer kills the app on Linux**

The first page open took the whole application down on Linux: the web
context was built before the toolkit it needs had started, so the result
was a crash instead of an error, and the control socket answered that
its worker had stopped because there was no longer a process to answer
it. Startup now brings that toolkit up first, and one that cannot start
is reported inside the browser pane instead of ending your session.

**AppImage installs register themselves**

Installing from the AppImage left no menu entry and no icon, so
launchers that only list installed applications never offered the app.
The entry and the icon the image already carries are now written to your
user account, pointing at the installed executable. The binary is
written first too: a failure in that desktop integration used to abort
the install and delete the download, leaving you with nothing.

**Interface fixes**

Tab titles are held to a single line, so a summarizer or a rename that
answers on two lines can no longer paint across the neighbouring tab.
Switching worktrees reloads the tab strip every time, even while another
worktree still has work waiting, so the tabs on screen always belong to
the worktree you clicked. A tab shows its status with the same bloom as
its sidebar row, so the two can no longer disagree. The rest of the
sidebar chrome follows the interface font size from Settings. A long
question title on the pending-question bar is truncated, and its Show
control stays inside the card. Worktree menus no longer print an
explanation beside a greyed-out entry, and the new worktree dialog
closes with its own control or confirms with Create, not only from the
keyboard.
