Right-clicking in the file editor now opens a menu. It had none before:
the terminal has had one for a while, the editor never did, so there was
no way to copy a selection, paste into a file, or hand a piece of code to
the agent already running in that worktree without leaving the editor.

**Hand a selection to the agent you already have open**

"Add to Agent Thread" sends the selected code to the ACP chat of the
worktree the file belongs to. It arrives as a located reference — the
path and the line range first, then the code in a fenced block tagged
with the file's language — so the agent can act on the file rather than
on a floating quotation. The snippet is dedented on the way, so code
copied out of a nested block does not arrive buried under its original
indentation.

It is added to whatever you were already typing rather than replacing
it, and your attachments and mentions survive. A half-written prompt is
no longer something you can lose by right-clicking. Terminal panes are
deliberately not a target: pasting into a busy agent's prompt is
interference.

**Clipboard, and a copy that pastes flush left**

Cut, Copy and Paste work on the editor selection. "Copy and Trim" copies
the selection with the indentation every line shares removed, which is
what you want when lifting a function out of a deeply nested block to
paste somewhere else.

**Reach the file outside Sirio**

"Reveal in File Manager" opens the file in the system file browser, and
"Open in Terminal" opens a terminal in its directory. "Open Markdown
Preview" appears only on Markdown files.

**Link to a line, and see a file's history**

"Copy Permalink to Line" copies a GitHub URL for the selected lines,
pinned to the commit currently checked out rather than to a branch, so
the link still points at the same code after the branch moves. "View
File History" opens the History panel filtered to that one file.

**Entries that cannot be used say why**

An entry that does not apply is hidden; an entry that could apply but
cannot right now stays visible and shows its reason underneath — "Select
some text first", "No agent chat open in this worktree", "This
repository has no GitHub remote". A greyed-out row that explains nothing
leaves you guessing which of several conditions is the one you have not
met.
