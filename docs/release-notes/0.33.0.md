The file tab has a new code editor, `sirioctl` is on your PATH wherever you
open a terminal, and the second pane now opens only when you put something in
it. A project on an unplugged disk is no longer lost.

**A new code editor**

The file tab now draws and edits code with Ely's code editor.

- **Still there.** Syntax colour, the language server's diagnostics, hover
  and go to definition, links and the context menu work as before.
- **Git marks in the gutter.** Added, changed and removed lines are marked
  beside the code; click a mark to see its hunk in place.
- **Find and replace** in a bar docked above the code, with match case, whole
  word and regular expressions.
- **A breadcrumb** above the code shows the file's path and the symbols
  around the cursor.
- **A status row** below it shows the branch, the language server, the
  cursor's position, the indentation, the line ending and the language, with
  the notification bell at its end.
- **Line endings are kept.** A file with Windows line endings is saved with
  them.
- **Settings → Editor** is a new page for the editor's options.
- Multiple cursors are added with **Shift+Alt+Up/Down**; Ctrl+Alt+Up/Down
  still moves between panes.

**`sirioctl` always there**

Agents can drive Sirio through `sirioctl` from any terminal, so Sirio now
makes sure it is there.

- **On your PATH.** Sirio keeps its own copy of `sirioctl` up to date and
  links it into `~/.local/bin` on Linux, `/usr/local/bin` or `~/.local/bin`
  on macOS and your user `Path` on Windows. Settings → General has a CLI
  card with *Install in PATH*. A file Sirio did not put there is never
  replaced.
- **Your own environment.** Terminals, agents, git and links now start in
  the environment you launched Sirio from, never in the AppImage's own.
- **Sirio's skill for every agent.** *Install Skill* now writes it for
  Claude Code, Codex, Pi, OpenCode and Oh-My-Pi without `npx`, and new
  worktrees get it too, kept out of git.

**The second pane on demand**

- The centre starts with one pane. The second appears when something opens
  in it and goes away with its last tab.
- A new **Open** view in the right panel lists what you can open: Terminal,
  Chat (with the agents on your PATH), Browser, Changes, Open File and
  Project Settings.
- Dragging a tab to the right shows where the second pane will open.
- Ctrl+Shift+B still hides or shows a second pane that has tabs.

**Fixes**

- Launching Sirio while a project's disk was unplugged deleted that project,
  with its worktrees, tabs and chats. It is now kept, its worktrees marked
  *(missing)*, and it is whole again once the disk is back.
- A chat no longer folds older turns by itself. Click a turn's footer to fold
  it.
- Selecting text in a chat response or the Markdown Preview now highlights
  the first letter of every wrapped line.
- A worktree's *N agents* counted plain shells and empty chats; it now
  counts only agents.
