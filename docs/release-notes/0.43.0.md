A native Claude chat now shows more of a permission request, and the
session panel lists Claude Code's permission rules. Renaming a chat's tab
now renames its session in Claude Code too.

**Permission requests say more**

The permission card of a native Claude chat used to show "Permission
requested" and the command exactly as Claude Code sent it. It now shows what
Claude Code says about the request:

- The caption is Claude Code's own title for the request, when it sends one.
- Under the command come Claude Code's description and the reason it is
  asking, for example *Matches an ask rule in user settings*. **Path** shows
  the file a shell command writes to, and **MCP server** shows the server a
  tool belongs to.
- Hidden characters in a command can no longer disguise it. A control,
  zero-width or right-to-left character shows as its code, for example
  `⟨U+202E⟩`.
- When Claude Code asks for the answer to default to no, the card starts on
  **Reject**, and a digit key does not answer it. When Claude Code withholds
  **Always allow**, the card does not offer it.

ACP chats keep the plain card.

**Claude Code's rules in the session panel**

The session panel of a native Claude chat has a new **Permissions** card. It
lists the allow, ask and deny rules and the extra directories that Claude
Code applies to the session, each with the settings file it comes from. The
card is read-only. It refreshes when the panel opens, when the chat
reconnects, after **Always allow** and at the end of each turn. Claude Code
versions before 2.1.325 cannot list their rules, so the card does not appear
with them.

**Renaming a tab renames the Claude session**

Renaming a native Claude chat's tab used to change only Sirio's tab. Claude
Code now gets the name as well, so `claude agents` lists the session under it
and `claude --resume "<name>"` finds it. This covers the tab bar's inline
editor and **Set Title**. A title Sirio picks on its own, from the first
prompt or the summarizer, stays in Sirio. If Claude Code refuses the name,
the chat shows *Claude Code kept its earlier name* with the reason. Claude
Code shortens a name longer than 200 characters.
