0.11.0 shipped the darker Neutral shell but never reached a build: two
theme checks still described the palette it replaced. This release is
those two checks, brought back in line — the same app, now able to
release.

**Readable text on the status chips**

The "not installed" pill and the terminal-only ACP badge paint their
text on a saturated red or amber fill. That text took its colour from
the pane, which Neutral's new ladder moved a rung darker in light mode
— enough to drop the red chip to 3.89:1 and make the label hard to
read. It now takes the page colour, which is the plane it was always
meant to sit against, and clears WCAG AA in both appearances again.

**No visible change otherwise**

The light coral was retuned in 0.11.0 to stay legible on the new
surfaces; the conformance check that pins it still named the old value.
Nothing about the colour moves here — only the check that guards it.
