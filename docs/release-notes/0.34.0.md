The file tab has a drawer with Problems and a search across the worktree, a
Claude chat can show what fills its context and which connectors it has, and
Clone Repository now works on a fresh install and for large repositories.

**Problems and Search in the editor**

A drawer under the code, one per worktree, with two tabs. From a file tab,
Ctrl+J (Cmd+J on macOS) opens and closes it, and Ctrl+Shift+F (Cmd+Shift+F)
opens Search.

- **Problems** lists what the language servers report across the worktree,
  not only in the open file. The drawer opens by itself on an error you have
  not seen yet; warnings never open it.
- **Search** looks through the worktree's files as git lists them, with match
  case, whole word, regular expressions and include and exclude patterns. An
  unsaved tab is searched as you see it.
- **Replace all** replaces the text literally and leaves files with unsaved
  changes alone. It also skips links, read-only files and anything outside the
  worktree, and lists every file it skipped and why.
- The drawer's height and open tab are kept per worktree, across a relaunch.

**A session panel beside the chat**

The button after the composer's attach button opens a column beside the
chat, with four cards.

- **Environment**: the project, the chat's own folder and its branch.
- **Context**: what fills the context window, grouped by where it comes from
  (memory files, plugins and skills, MCP tools, the conversation), heaviest
  first. A memory file opens in a tab, so you can see what to trim.
- **Connectors**: the Claude session's MCP servers and their state, with
  *Sign in* and *Reconnect*.
- **Change request**: the pull or merge request of the chat's branch. Click
  it to open its tab.

On a narrow chat the column lies over the transcript instead of beside it.
Whether it is open is kept per chat. Other agents show only the context's
total.

**Bypass permissions in Claude chats**

The mode picker of a Claude Code chat now offers *Bypass permissions*. It
asks for confirmation first, and nothing else switches to it: *Always allow*
never does.

**Fixes**

- **Clone Repository** failed on a fresh install, because its folder did not
  exist yet, and cut off any clone longer than ten seconds. It now creates the
  folder and keeps going while git is making progress. A failed clone no longer
  leaves a half-made folder behind that blocks *Retry clone*. A private
  repository needs credentials git already has (an SSH key, a credential
  helper, `gh auth setup-git`): the clone no longer waits on a login prompt.
- A code block or table in a chat response or the Markdown Preview, and a
  tool call's diff, that is wider than its column now has a horizontal
  scrollbar, and its last characters are no longer hidden under the edge.
- A greyed-out entry in a tab's right-click menu no longer draws its reason
  past the menu's edge.
- The Open list offered no Claude chat when only `claude` itself was on your
  PATH.
