## Defects found this pass

None against this section's own row contracts. The one adjacent issue I noticed while working through
`DIFF-04`'s territory — `diff::stats()` running one whole-repo `numstat` call that a single unreadable
tracked file can poison, taking down the *entire* Changes tab instead of just that file's row — is
**already recorded** as a live-reproduced defect under `F-CHG-15` in `docs/linux-rewrite/fullapp/F-CHG.md`
(a different critic, a different section). I did not re-drive it myself this pass and am not claiming it
here to avoid double-counting someone else's finding; flagging the cross-reference only because it sits
squarely inside `tiller_git`'s `numstat`/`run_accepting` machinery that this section's rows also cover.

The one real gap I did find and own is under `F-GIT-RUN-01`/`F-GIT-BRANCH-01` above: `GitCancellationToken`
and `GitBranches::list` are both **fully implemented and unit-tested but have no live UI caller** —
cancellation has no caller anywhere (not even a testability door), and branch-listing's only live route
is a control-socket door added specifically so a critic could exercise it. Neither breaks its own row's
contract (both rows are about the `tiller_git` layer's own behavior, which is correct), but both are
worth a future pass's attention if "branch listing" or "cancel a running clone" are meant to become real
user-facing features rather than internally-correct, externally-invisible plumbing.
