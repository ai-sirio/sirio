Come si comporta (mie proposte)

  • Ogni livello è ordinato per peso, il più pesante in alto.
  • All'apertura sono aperti i gruppi di primo livello e chiusi i singoli plugin. Quello che apri o chiudi resta così ai turni successivi.
  • Ogni riga per cui Claude indica un file è un link (in blu) che apre quel file in un tab: file di memoria, agenti, skill (anche quelle dei plugin). Sono numeri veri di questa sessione: in plugin-dev pesano più i 3 agenti (~0,4k ciascuno) delle skill (0,04–0,2k).
  • Oltre una decina di voci, il resto finisce in «altri N» con il totale, ed è apribile anche quello.
